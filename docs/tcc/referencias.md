# Referências

**MobileNetV2 (arquitetura do modelo):**
Sandler, M., Howard, A., Zhu, M., Zhmoginov, A., & Chen, L.-C. (2018).
*MobileNetV2: Inverted Residuals and Linear Bottlenecks*. CVPR 2018.
https://arxiv.org/abs/1801.04381

**Dataset — DogPoseCV:**
Stock, J., & Cavey, T. (2021). *Who's a Good Boy? Reinforcing Canine
Behavior in Real-Time using Machine Learning*. arXiv:2101.02380.
https://arxiv.org/abs/2101.02380
Dataset card: https://huggingface.co/datasets/stockeh/dog-pose-cv
Repositório: https://github.com/stockeh/canine-embedded-ml

**Dataset base — Stanford Dogs Dataset:**
Khosla, A., Jayadevaprakash, N., Yao, B., & Fei-Fei, L. (2011). *Novel
Dataset for Fine-Grained Image Categorization*. First Workshop on
Fine-Grained Visual Categorization (FGVC), CVPR 2011.
http://vision.stanford.edu/aditya86/ImageNetDogs/

**Transfer Learning:**
Pan, S. J., & Yang, Q. (2010). *A Survey on Transfer Learning*. IEEE
Transactions on Knowledge and Data Engineering, 22(10), 1345-1359.
